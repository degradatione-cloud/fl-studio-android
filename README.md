# FL Studio для Android (секвенсор-клон)

**Честно: это не порт FL Studio.** FL Studio — проприетарный DAW под Windows/macOS, миллионы строк,
собственный аудио-движок, VST-хост и закрытый исходник: «полностью портировать» его нельзя ни за ночь,
ни вообще силами одного человека. Здесь — рабочий мобильный секвенсор **в логике FL**: channel rack,
step-сетка, синтезированные инструменты, мастер-шина, экспорт WAV.

## Что нового в 0.2

- **Дружелюбнее**: крупные подписи у каждого ползунка («громкость», «тон», «затухание»),
  карточки каналов с счётчиком включённых шагов, подсказка «Тишина в эфире» с кнопкой
  **Демо-бит** (сразу ставит кик/снейр/хэт/бас), кнопка «?» со справкой на человеческом.
- **Ландшафт**: переверни телефон — слева список каналов, справа большой редактор
  выбранного (клетки 46 dp вместо 32), всё остальное на месте. Портрет работает как раньше.
- Анимации: клетки подпрыгивают на текущем шаге, кнопки пружинят под пальцем.
- Статус в шапке: «играет / на паузе», BPM и номер текущего шага.

## Что реально работает

- **Channel rack**: 8 каналов по умолчанию (Kick, Snare, Hat, Clap, Bass, Lead, Pad, Pluck),
  можно добавлять свои и менять инструмент тапом по имени.
- **Step-секвенсор**: 16 шагов, сетка 8+8 под палец, подсветка текущего шага, сильные доли помечены.
- **Синтез без сэмплов**: каждый инструмент — свой генератор (синус с частотным свипом у кика,
  шум с хайпассом у хэта, пила с one-pole фильтром у баса, три расстроенные пилы у пэда и т.д.).
- **Транспорт**: play/stop, BPM 40–240, мастер-громкость, mute всего микса.
- **Экспорт WAV**: 2 такта, 16-bit stereo 44.1 kHz → `Download/FLMobile`.
- **Паттерн сохраняется** в SharedPreferences, при запуске поднимается обратно.
- Всё считается на телефоне, ни сети, ни аккаунтов.

## Чего нет (и почему)

- Пиано-ролла, плейлиста, автоматизации, эффектов (реверб/дилей), VST, сэмплерных банков.
- Импорта/экспорта `.flp` — это закрытый формат.
- Записи с микрофона и MIDI.

Это следующий шаг: пиано-ролл, эффект-шина, шаринг паттернов `.flpattern`.

## Тесты

`./gradlew :app:testDebugUnitTest` — раундтрип паттерна, длина и громкость рендера,
тишина при пустом паттерне, корректность WAV-заголовка.
